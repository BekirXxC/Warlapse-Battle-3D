# Changes / Değişiklikler

## 7.6.1 — 14 Kasım 2026

Publication package for GitHub distribution. The mod defaults to English (ENG); use TR / ENG in the main menu or 3D HUD to switch. Hold Ctrl to use the 3D selector. An explicit selection is saved for the next launch.

GitHub üzerinden dağıtım için yayın paketi:

- Modun kurulu durum metni, bilgi paneli, kontroller ve uyarılar için varsayılan İngilizce; ana menüde ve 3D arayüzünde kaydedilen TR / ENG dil seçimi.
- GitHub indirme ve kurulum akışına göre düzenlenmiş açıklamalar; Türkçe ve İngilizce Workshop metinleri.
- Ana menüde sade logo ve sürüm rozeti; mod bilgi paneli ve GitHub Releases bağlantısı.
- Logo, tanıtım illüstrasyonu ve açıkça etiketlenmiş gerçek oyun görüntüleri.
- Ayrı oyun kopyası kullanan kurulum ve masaüstü kısayolu; özel hedefi izleyen başlatıcı.
- Kaynak derleme ve Windows paketi oluşturma araçları.

Oynanış, 7.6.0 temelini kullanır. Saldırı ve hasar birlik düzeyinde hesaplanır.

## 7.6.0

- WASD yalnızca seçilen 3D askeri hareket ettirir. Birlik hedefinde askerler ayrı adımlarla ilerler.
- Sabit güneş yönüne bağlı asker gölgeleri ve daha hafif gölge çizimi.
- Daha çeşitli bitki örtüsü, açık havada güneş kamaşması ve dış araziye yumuşak geçiş.

- **7.4:** Yağmur ve rüzgâr efektleri, 3D vuruş izleri ve çimlerin ayak altında eğilmesi.
