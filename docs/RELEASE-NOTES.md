# Warlapse Battle 3D 7.6.1

Watch the battle from above. Experience it through a soldier's eyes.

A community-made 3D battlefield, free-camera and soldier-camera mod for **Warlapse on Windows / Steam**, for offline battles.

[Project page](https://github.com/BekirXxC/Warlapse-Battle-3D) · [Windows download](https://github.com/BekirXxC/Warlapse-Battle-3D/releases/latest/download/Warlapse-Battle-3D-7.6.1-Windows.zip)

## Quick start

**Choose the correct download:** `Warlapse-Battle-3D-7.6.1-Windows.zip` is the actual playable mod installer. `Warlapse-Battle-3D-Workshop-Duyuru-1.0.0.zip` is a separate, empty Workshop announcement for publishers; it contains only metadata, the supplied logo and a readme. Subscribing to that notice does not install 3D. [Announcement package details](https://github.com/BekirXxC/Warlapse-Battle-3D/blob/main/docs/WORKSHOP-ANNOUNCEMENT.md).

Download **Warlapse-Battle-3D-7.6.1-Windows.zip**, extract all files and run `Kur.cmd`. Launch using the desktop shortcut or `Oyunu-Ac.cmd`. Start an offline battle, finish deployment and press **G**.

The mod starts in **English (ENG)**. Installed status, mod information, controls and warnings use English by default. Use **TR / ENG** on the main-menu badge or 3D HUD to change the mod language. In 3D, hold **Ctrl** to show the cursor. Your explicit selection is saved for the next launch; the game's language setting is separate.

## In this package

- English-first bilingual documentation and TR/ENG mod text.
- A separate-copy installer, desktop shortcut and launcher that follows a custom installation target.
- A simple main-menu logo/version badge, information panel and GitHub Releases button.
- Promotional artwork, clearly labelled gameplay screenshots and TR/EN Workshop descriptions.
- Source build and Windows packaging tools.

7.6.1 uses the 7.6.0 gameplay foundation: independent visual movement of the selected soldier, fixed-direction soldier shadows, more varied vegetation, sunlight glare and softer landscape transitions. Combat and damage remain unit-based.

## Requirements

Windows / Steam Warlapse must already be installed. The installer checks the supported game build by SHA-256. Installation creates a separate game copy; that copy and the Steam game share saves and settings. Game files are not included. The 3D features are for offline battles. Enhanced graphics start disabled and can be toggled with F8.

## Türkçe

**Doğru dosyayı seçin:** Gerçek mod `Warlapse-Battle-3D-7.6.1-Windows.zip` dosyasıdır. `Warlapse-Battle-3D-Workshop-Duyuru-1.0.0.zip` ise yalnızca paket bilgisi, logo ve açıklama içeren ayrı bir boş duyuru paketidir; 3D modu kurmaz.

**Savaşı haritadan izle. Sonra bir askerin gözünden yaşa.**

Windows ZIP'inin tamamını çıkarın, `Kur.cmd` dosyasını çalıştırın ve masaüstü kısayolundan veya `Oyunu-Ac.cmd` ile başlatın. Çevrimdışı savaşta konuşlandırma bittikten sonra **G** ile 3D'ye geçin.

Mod varsayılan olarak **İngilizce (ENG)** açılır; kurulu durum metni, mod bilgisi, kontroller ve uyarılar başlangıçta İngilizcedir. Ana menüden veya 3D arayüzünden **TR / ENG** seçin. 3D'de **Ctrl** basılı tutarak imleci gösterin. Dil seçimi sonraki açılış için kaydedilir; oyunun kendi dil ayarı ayrıdır.

Bu paket 7.6.0 oynanış temelini GitHub kurulumu, iki dilli mod metinleri, sade logo, mod bilgi paneli, yayın görselleri ve Workshop açıklamalarıyla sunar. Saldırı ve hasar birlik düzeyinde hesaplanır. Kurulum ayrı bir kopya oluşturur; Steam oyunu ve modlu kopya kayıtları ve ayarları paylaşır.
